## 🏆 Featured Projects

### [Personage - AI personal assistant](https://github.com/Doremi203/personage)
Cloud based AI system which proactively follows event feed of user connected sources to create tasks and help plan your life.
- **Tech Stack:** Go, Python, React, PostgreSQL, Valkey, SQS, OpenRouter, LLM
- **Features:** Autonomous life tasks planner with no supervisor based on users own event feed.

### [Couply - Online Dating Service](https://github.com/Doremi203/couply)
Modern PWA dating app with photo verification, matching, blocking, and payments.
- **Tech Stack:** Go, Python, React, PostgreSQL, Valkey, SQS.
- **Features:** Oauth 2.0 Login/Registration, Feed, Filters, Moderation, Notifications.

### [CoffeeScout - Coffee Ordering App](https://github.com/Doremi203/CoffeeScout)
CoffeeScout is a mobile application that allows users to find coffee shops in Moscow, order their favorite coffee, as well as leave reviews and ratings about them.
- **Tech Stack:** C#, React, PostgreSQL.
- **Features:** Order management, Coffee search and navigation integration.
